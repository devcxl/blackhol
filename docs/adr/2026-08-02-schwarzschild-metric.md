# ADR-002: Schwarzschild 度规 vs Kerr 度规

| 字段 | 值 |
|------|-----|

| 状态 | Accepted |
| 决策者 | devcxl |
| 相关 | PRD §3, ADR-001 |

## 背景

黑洞 raymarching 需要选择一个时空度规来描述光线在引力场中的运动。两个主要选项：
- **Schwarzschild**：静态、非旋转黑洞（单参数：质量 M）
- **Kerr**：旋转黑洞（双参数：质量 M + 角动量 a）

## 决策

**采用 Schwarzschild 度规近似。**

## 选项

### 选项 A：Kerr 度规（否决）

- 更物理准确（真实黑洞都有旋转）
- 但测地线方程涉及 4 个耦合 ODE，数值积分复杂
- 引入了 ergosphere、赤道面不对称等视觉差异
- 在典型观察距离下，Kerr 帧拖拽视觉效应微弱
- shader 复杂度至少 2×，调试困难显著增加

### 选项 B：Schwarzschild 度规（采用）

- 球对称，光线在单一平面上运动（2D 简化）
- 一阶偏转近似即可产生视觉正确的透镜效果
- 产生《星际穿越》标志性的"双像"吸积盘
- 代码量少、shader 调试可行

## 后果

- 正面：实现复杂度可控，视觉效果已满足 PRD 要求
- 负面：无法表现旋转黑洞的 frame-dragging 效果
- 未来可升级：预留 Kerr 度规切换常量，后续可选升级

## 为什么不用 Kerr？

Kerr raymarching 的测地线方程求解比 Schwarzschild 复杂一个数量级，而视觉增益极小——只有专业天体物理学可视化才真正需要。本项目目标是"电影感"，而非物理模拟精度。Schwarzschild 已经足够产生标志性的双像和爱因斯坦环。
