# PRD：星际穿越风格黑洞可视化

> 状态: Draft · 来源: docs/dev/decision-map.md

## 1. 背景与目标

在网页上渲染一个类似电影《星际穿越》中的黑洞：事件视界、吸积盘、引力透镜、粒子效果，并部署到 Cloudflare Pages。目标是打造沉浸式的展示型页面，用户在浏览器中即可体验强引力场下的光线弯曲效果。

## 2. 范围

### 2.1 功能范围（In Scope）

| 功能 | 描述 |
|------|------|
| 黑洞渲染 | 自定义 GPU shader raymarching（Schwarzschild 度规近似），逐像素追踪光线在强引力场中的弯曲 |
| 事件视界 | 光线落入视界半径内即被吸收，渲染为纯黑圆，边缘有光子环（photon ring）辉光 |
| 吸积盘 | shader 内隐式薄盘几何；温度梯度配色（内盘白蓝 → 外盘暖橙）；多普勒双峰明暗（朝向侧亮、背向侧暗）；引力透镜产生盘面双像（上方像 + 下方像） |
| 引力透镜 | 背景星空与吸积盘光线在黑洞附近被弯曲，形成爱因斯坦环附近的光弧 |
| 粒子效果 | ① 背景星空粒子：远场光点，随光线弯曲被透镜扭曲；② 吸积盘物质粒子流：轨道碎屑轨迹，向视界螺旋吸入 |
| 交互 | 初始自动旋转展示；鼠标拖拽旋转视角、滚轮缩放（OrbitControls） |
| 后期 | Bloom 辉光强化高温盘面与光子环 |
| 部署 | Cloudflare Pages 静态托管 |

### 2.2 非目标（Out of Scope）

- 物理级精确广义相对论解算（仅视觉近似）
- 参数调节面板（质量/温度/转速等）
- 音效、多语言、账号体系
- 移动端触控手势的完整优化（仅保证可运行与降级）

## 3. 关键技术决策（源自 Decision Map）

1. **渲染核心**：fragment shader raymarching（Schwarzschild 近似）+ Three.js 管理场景/相机与后期（Bloom）
2. **吸积盘风格**：星际穿越写实风（温度梯度 + 多普勒双峰 + 薄盘）
3. **交互**：初始自动旋转 + OrbitControls（拖拽/缩放）
4. **性能**：桌面高画质；移动端自动降级
5. **粒子**：背景星空粒子（透镜扭曲）+ 吸积盘物质粒子流

## 4. 性能目标与降级

| 档位 | 条件 | 配置 |
|------|------|------|
| 高画质（桌面） | 桌面设备 | dpr ≤ 1.5、raymarch 64 步、粒子全量、目标 60fps |
| 降级（移动端） | 移动设备 / 低端 | dpr 0.75–1、raymarch 32 步、粒子减半、允许 30fps 档 |

降级依据：`devicePixelRatio` + 设备类型（`navigator.userAgentData`/UA 探测），必要时按实测 FPS 二次降级。

## 5. 页面形态

- 单页全屏沉浸式 Canvas（无多余 UI）
- 轻量覆盖层：顶部标题（如 "BLACK HOLE · Gargantua"）、底部操作提示（拖拽旋转 / 滚轮缩放）、加载态
- 技术栈：React + Three.js + TypeScript + Vite

## 6. 部署

- 平台：Cloudflare Pages（连接 GitHub 仓库，自动构建）
- 构建命令：`npm run build`，输出目录：`dist`
- 静态托管，无需后端

## 7. 验收标准

1. 页面加载后黑洞渲染可见：事件视界为纯黑圆，边缘有光子环
2. 吸积盘呈现双像（上下两像）且有多普勒双峰明暗差异
3. 背景星空在黑洞附近呈透镜弯曲光弧
4. 吸积盘粒子流可见（轨道碎屑向视界螺旋）
5. 默认自动旋转；鼠标拖拽可改变视角、滚轮可缩放
6. 桌面端 60fps 流畅（主流 GPU）；移动端可运行且自动降级
7. 部署到 Cloudflare Pages 后可公网访问
8. 全程 TDD：渲染核心的纯逻辑部分（色温映射、多普勒因子、质量参数化等）有单测覆盖

## 8. 风险与开放项

- raymarching 数值稳定性：步长过大导致光子环闪烁 → 通过步数与容差调整
- 粒子流与 raymarching 盘面的视觉融合 → 需要视觉调优迭代
- 移动端 GPU 算力差异大 → 降级阈值需实测校准
